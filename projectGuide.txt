NocturnalStudios – projectGuide.txt
===================================

Overview
--------
This repo contains a static Engine library and a Sandbox game executable.

Root layout
-----------
• CMakeLists.txt      -> top-level project (project name: NocturnalStudios)
• Engine/   -> static library “Engine” (include/, source/, CMakeLists.txt)
• Sandbox/  -> game wrappers; adds subfolders with their own CMakeLists
    |_ NocturnalGame/  -> executable “NocturnalGame”
       • assets/ -> audio, fonts, levels, prefabs, scenes, shaders, textures, config.json
       • main.cpp, Game.cpp, Game.h, imgui.ini, CMakeLists.txt
• lib/  -> third-party deps: fmod, freetype, glew, glfw, glm, imgui, rapidjson, stb
• cmake/ -> Utilities.cmake, ImportDependencies.cmake(included by name)
• build/ -> generated by CMake (solution + intermediates)
• AccessGameEng.bat  -> helper menu for configure/build
• editorGuide.pdf -> editor usage guide
• NocturnalStudios_ReadMe.txt → team/readme notes

Toolchain / Requirements
------------------------
• Windows 10/11 + Visual Studio 2022 (Desktop C++ workload)
• CMake ≥ 3.20 (VS 2022 includes this)
• OpenGL runtime (Windows opengl32)
• Optional audio: FMOD SDK files under lib/fmod ( CMake copies the DLL after build when present)

Configurations
--------------
• Debug – development (recommended for editor usage)
• Release – optimized (for demo / playback)

How to generate the Visual Studio 2022 solution
-----------------------------------------------
Option A – Use the included script (recommended)
1) Double-click **AccessGameEng.bat**
2) Choose:
   [1] Configure -> runs `cmake -S . -B build` and generates **build/NocturnalStudios.sln**
   [2] Build Debug -> `cmake --build build --config Debug` (optional)
   [3] Build Release-> `cmake --build build --config Release`(optional)

Option B – Manual commands (from repo root)
    cmake -S . -B build
    cmake --build build --config Debug
    cmake --build build --config Release

Opening and running
-------------------
• Open **build/NocturnalStudios.sln** in Visual Studio 2022.
• Startup project is set to **NocturnalGame** at the top level CMake.
• **Working directory** is set to the game folder:
  Sandbox/NocturnalGame   (so relative paths find assets/)
• Press F5 to run in the chosen configuration.

Editor usage (real-time vs offline)
-----------------------------------
• Real-time editor/ImGui overlay is available in **Debug** builds.
• For “offline/demo only”, build **Release** and run.


3rd-party integration (as configured)
-------------------------------------
• GLFW, GLEW, ImGui, FreeType -> added via `ImportDependencies.cmake` and linked by Engine/CMakeLists.
• GLM, RapidJSON, stb -> header-only INTERFACE targets that propagate include paths when linking Engine.
• OpenGL -> on Windows links with **opengl32**.
• FMOD -> linked when `lib/fmod` exists; **NocturnalGame**’s CMake copies the correct FMOD DLL
  next to the .exe after build (Debug uses FMOD_DLL_DEBUG; non-Debug uses FMOD_DLL_RELEASE).

Asset locations
---------------
• All game data loads relative to **Sandbox/NocturnalGame/assets/**:
  audio/, fonts/, levels/, prefabs/, scenes/, shaders/, textures/, and **config.json**.

Troubleshooting
---------------
• Missing FMOD DLL at runtime → ensure `lib/fmod` is populated; rebuild. (Build still succeeds without audio.)
• Black window / missing textures → confirm we're launching with working directory set to Sandbox/NocturnalGame.
• “Headers not found” -> regenerate with Configure (AccessGameEng.bat option [1]) so new files are picked up.
• Solution didn’t appear -> delete the `build/` folder and re-run Configure.

Regeneration commands (quick reference)
---------------------------------------
• Configure:  `cmake -S . -B build`
• Build Dbg:  `cmake --build build --config Debug`
• Build Rel:  `cmake --build build --config Release`
